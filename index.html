Grill before you build

A method-and-discipline course for daily Claude Code users: front-load context with AI before any code is written, then review its output like a senior engineer — staying personally in control of every step.

Mission: fewer review rounds, you in control

Lessons

  1. 00Install the skill, once, for every repo Set up the grilling skill so it's available in any repository.
  2. 01Grill before you build Turn the conversation around so the AI interrogates you first.
  3. 02Answer like the expert in the room How to respond during a grilling session to sharpen the plan.
  4. 03Leave artifacts the team inherits CONTEXT.md, ADRs, and the written understanding that outlives the chat.
  5. 04Drive the implementation, don't hand over the wheel Stay in control of each step instead of delegating to an autonomous agent.
  6. 05Local review — read the diff like a senior Catch issues against a personal checklist before a colleague ever sees them.
