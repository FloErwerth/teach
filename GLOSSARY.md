# AI-Assisted Coding (Human-in-the-loop) Glossary

The canonical language for this workspace. Terms are promoted here only once the
learner can use them correctly.

## Terms

**Grilling**:
A session where the AI interrogates *you* about a plan — one question at a time,
recommending an answer each time — until you reach a shared, written understanding
before any code is written.
_Avoid_: Prompting, chatting, brainstorming

**Context-first**:
Investing effort in establishing shared understanding and constraints *before*
generating code, rather than correcting code after the fact.
_Avoid_: Prompt-first, vibe coding
