Lesson 00 · Human-in-the-loop AI coding

Install the skill, once, for every repo

Before you can grill, the grill-with-docs skill has to exist on your machine — and it should live globally, so the discipline travels with you to every project and every teammate can install it the same way.

Mission: the workflow is one command away, everywhere

Why global, not per-project

A grilling-first workflow is only a habit if it's always there. Install the skill into a single repo and you'll skip the grill the moment you switch projects — which is most of the day. A global (user-level) install registers it once for your account, so grill-with-docs is available in every repo you open. Your colleagues run the exact same command on their machines; the team converges on one shared method instead of one person's local trick.

The tool: skills (skills.sh)

Matt Pocock's skills ship through the open skills CLI, run via npx — the same package runner that comes with Node.js. It's agent-agnostic (Claude Code, Cursor, Copilot, and ~20 more) and cross-platform, so the one command below works identically on macOS and Linux. The catalogue, including grill-with-docs, lives at github.com/mattpocock/skills.

Prerequisite: Node.js

You need npx, which ships with Node. Check with node -v. If it's missing:

# macOS (preferred)
brew install node

# Linux (Debian/Ubuntu) — or use your distro's package / nvm
sudo apt install nodejs npm

Install it

One command starts the installer — nothing to memorise:

npx skills@latest add mattpocock/skills

It then walks you through a short questionnaire. Answer the three prompts and you're done:

  1. Which skill? Pick grill-with-docs from the list (it's the one this course is built on).
  2. Which agent? Select claude — that's Claude Code, the agent you'll run the grill in.
  3. Project or global? Choose global. This is the answer that makes the skill follow you into every repo, instead of living in just one folder.

That third answer is the whole point of this lesson: global registers the skill once for your user account, so grill-with-docs is there in every project you open and your teammates run the identical command and answer the same three prompts to converge on the same method.

Where it lands — and how to verify

A global install drops the skill's source into a shared, agent-agnostic directory and symlinks it into each agent's skills folder. The same layout on macOS and Linux:

~/.agents/skills/grill-with-docs            # the actual skill (source of truth)
~/.claude/skills/grill-with-docs  ->  ../../.agents/skills/grill-with-docs   # symlink Claude Code reads

That symlink is why this is the primary source the rest of the course points at (SKILL.md). Confirm the install two ways:

  1. npx skills@latest list (or skills ls) — shows what's installed and where.
  2. In Claude Code, type /grill-with-docs. If it resolves to a command, you're done — that's the skill you'll run in Lesson 1.
Keeping the source in ~/.agents/skills and symlinking into each agent means one update propagates everywhere. To refresh later: npx skills@latest update.

Your win for today

Install it globally, then have a teammate do the same

  1. Run the install command above. Verify with skills ls and by typing /grill-with-docs in Claude Code.
  2. Open a different repo and confirm the command is still there — that's the payoff of a global install.
  3. Send the one-liner to a colleague (Mac or Linux) and have them install it too. The whole point is a shared method — by Lesson 1 you both grill the same way.

Once /grill-with-docs resolves, you're ready for Lesson 1: turning the conversation around so the AI grills you.
